# Spiderium Whitepaper

## Vision and mission

A web holds together because every strand answers to every other. Spiderium takes that picture seriously: a network where many small participants move as one body, and where the signal is visible to anyone who looks.

The mission is to keep that signal honest. Facts are published once, in one place, and nothing is shown as true until it is stated.

## Roadmap

### Phase 1: Spin

Publish the site, the live board and the record of stated facts. Open the social channel.

### Phase 2: Anchor

State the contract address and wire it into the pinned slot. Publish the code and link it.

### Phase 3: Spread

Grow the lattice with community tools built on the same public data. Add detail panels for the boards people ask for.

### Phase 4: Colony

Hand more decisions to the community and document how they are made.
